# Credits & licenses

TAME Arranges My Errands, by Skitourer. Source: https://github.com/Skitourer/tame

In the terminal: `tk help credits`, and `tk help license` for the license texts, with the
exact versions installed on your machine.

## License

TAME is released under the [MIT License](https://github.com/Skitourer/tame/blob/main/LICENSE):
use it, change it, share it, as long as the copyright notice comes along.

## Thanks

To the [Taskwarrior](https://taskwarrior.org) team and community: TAME exists because
Taskwarrior showed how good a command-line task manager can be, and its open JSON format lets
tools talk to each other. TAME is an independent project and shares no code with it.
